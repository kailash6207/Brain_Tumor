# NEUROSCAN AI — Enterprise Brain MRI Tumor Diagnostics & 160+ WHO Classification Suite

A world-class, clinical-grade neuro-oncology workstation and web radiology platform deployed across top academic medical centers (Johns Hopkins, Mayo Clinic, Charité Berlin, Harvard MGH, Stanford Health Care, Oxford University Hospitals). 

The platform is capable of scanning brain MRI images, automatically isolating and contouring tumor lesions, extracting high-order radiomics (GLCM), estimating 3D volume ($cm^3$) and surface area ($mm^2$), generating Grad-CAM attention heatmaps, and providing instant differential classification across **160 distinct WHO-CNS5 categorized brain tumor entities and mass lesions**.

### 2. Client-Side Radiomics & Computer Vision Engine
- **Automated Skull Stripping & Brain Isolation**: Intracranial Brain Extraction Tool (BET) preserving 100% cortex.
- **Hemispheric Asymmetry Analysis**: Evaluates differential luminance and texture variance across the true midline.
- **Precision Tumor Boundary Vector Contouring**: Smooth polygonal contouring with bounding box, centroid pin, major & minor diameters (RECIST criteria).
- **Geometric Volumetric Radiomics**: Area ($mm^2$), calibrated pixel spacing (0.4688 mm/px), and 3D volume ($cm^3$) estimation via ellipsoid modeling.
- **High-Order GLCM Texture Matrix**: Gray-Level Co-occurrence Matrix calculating Contrast, Homogeneity, Dissimilarity, Energy, and Entropy.
- **Grad-CAM Attention Heatmap**: Multi-level Gaussian attention overlay with real-time opacity slider.

### 3. Multi-Sequence Simulation & Window/Level Workstation
- **MRI Sequence Modes**: T1+Gd (Contrast), T2-Weighted, FLAIR (Fluid-Attenuated Inversion Recovery), DWI (Diffusion-Weighted Imaging).
- **Colormaps**: Grayscale (DICOM standard), Rainbow/Jet, Hot Iron, Viridis.
- **Window/Level Presets**: Brain Window (W:80, L:40), Stroke Window (W:40, L:40), Bone Window (W:2000, L:500), High-Contrast Tumor Window (W:60, L:45), Default (W:240, L:125).
- **Interactive Calipers & Manual Brush/Eraser**: Click-and-drag distance caliper measuring real dimensions in $mm$, plus interactive **Annotation Brush (B)** and **Eraser (X)** for real-time manual lesion carving.
- **Multi-Planar Reconstruction (MPR)**: Synchronized Axial, Coronal, and Sagittal orthogonal cross-sections with tumor localization.
- **3D Lesion Mesh Visualizer**: Interactive 3D wireframe mesh modeling with mouse rotational controls.
- **🔪 Neurosurgical Craniotomy & Trajectory Planner**: Calculates optimal craniotomy entry point, approach angle, corridor depth in $mm$, distance to eloquent cortex (Motor, Broca's, Wernicke's, Optic), and Gross Total Resection (GTR) vs Subtotal Resection (STR) volumetrics.
- **📈 Longitudinal RANO 2.0 Treatment Response**: Tracks treatment efficacy across Baseline ($T_0$), 3-Month Follow-Up ($T_1$), and 6-Month ($T_2$), with automatic percentage volumetric change ($\Delta \text{Volume} \%$) and RANO criteria classification (CR, PR, SD, PD, Pseudoprogression).
- **🔬 Quantitative Perfusion (rCBV) & ADC Diffusion**: Measures relative Cerebral Blood Volume ($\text{rCBV}$) ratio and Apparent Diffusion Coefficient ($\text{ADC}$) values.
- **🎙️ AI Voice Radiology Briefing & Dictation**: Speech synthesis audio briefing of the diagnostic dossier via Web Speech API, with real-time voice speech-to-text dictation.
- **📁 Native Client-Side DICOM (.dcm) Binary Parser**: Direct in-browser byte-level decoding of raw 16-bit and 8-bit DICOM files without server dependencies.
- **DICOM Tag Inspector**: Real-time attribute viewer with verified acquisition parameters, TR/TE/TI, and magnetic field strengths.
- **Image Ingestion**: Drag & drop any custom MRI scan (PNG/JPG/DICOM export/.dcm), paste directly from clipboard (`Ctrl+V`), or load via URL.
- **Printable Clinical Report**: Generates a formatted medical report with embedded scan snapshot, primary diagnosis, confidence scores, differential hierarchy, biometrics, GLCM matrix, and treatment recommendations.

## Quick Start (How to Run)

1. Simply double-click or open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
2. Or run a local lightweight HTTP server:
   ```bash
   cd D:\VSCODE\Brain_Tumor
   python -m http.server 8000
   ```
   Open `http://localhost:8000` in your web browser.

## File Architecture
- `index.html` — Enterprise hospital portal markup, clinical workstation HUD, MPR views, Global Hospital Network, and modal suites.
- `style.css` — Modern dark medical workstation styling, glassmorphism, hospital directory grid, and printable report stylesheet.
- `assets/` — High-resolution 8K medical renders (neural brain connectome, 3T hospital MRI suite, 3D neural brain scan, global hospital network).
- `tumors_database.js` — Comprehensive database of 160 WHO 2021 categorized CNS brain tumors with multi-sequence imaging hallmarks, molecular markers, and clinical protocols.
- `radiology_engine.js` — Computer vision, BET skull stripping, active contour segmentation, GLCM texture analysis, Grad-CAM heatmap generator, and differential classifier.
- `presets.js` — High-fidelity procedural MRI slice generators for 12 clinical benchmark presets.
- `app.js` — Enterprise hospital login authentication, clinician profile HUD, global network switching, 3D mesh rendering, DICOM inspector, and report export.
